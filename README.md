# Game Patch Notes Feed

A news feed application to track patch notes and updates for games with randomizer tools in the Enigma Machine Randomizer Hub.

## Features

- **Multi-Game Support**: Tracks patch notes for 5 games:
  - Grim Dawn
  - Path of Exile 2
  - Soulframe
  - Warframe
  - Space Marine 2

- **Filter by Game**: Easily filter patch notes by specific games or view all at once

- **Direct Links**: Quick access to official patch notes sources for each game

- **Responsive Design**: Works seamlessly on desktop and mobile devices

- **Matching Style**: Uses the same green-themed dark design as the Randomizer Hub

## How to Use

1. Open `index.html` in your web browser
2. Browse all patch notes or use the filter buttons to view specific games
3. Click "Read More" on any card to visit the official patch notes page
4. Use the "Quick Links" section at the bottom for direct access to all sources
5. Click the refresh button to update the feed display

## Files

- `index.html` - Main application page
- `style.css` - Styling matching the Randomizer Hub theme
- `script.js` - JavaScript for filtering and displaying patch notes
- `README.md` - This documentation file

## Integration with Randomizer Hub

This application is designed to complement the Enigma Machine Randomizer Hub by helping you stay current with game updates that may affect your randomizer tools.

## Notes

Since many game patch notes are published on external sites with CORS restrictions, this application provides curated links to official sources rather than attempting to scrape content directly. This ensures you always get the most up-to-date and accurate information from the official sources.
